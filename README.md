## Sobre o projeto

O grupo está desenvolvendo, em parceria com um cliente real, uma proposta de solução digital para a **PKZ / One to One** — dois estúdios de treinamento esportivo (o PKZ focado em atletas jovens/adolescentes, e o One to One em personal training para todas as idades) que hoje operam com um aplicativo interno amador, planilhas e uso manual de IA (ChatGPT/Claude) para gerar relatórios de treino.

A partir de uma entrevista com os responsáveis pelo cliente (Henrique, Pedro e Eduardo), o grupo levantou as principais demandas — centralização de dados, automação de relatórios/dashboards, site institucional, notificações, cobrança, entre outras — e vai usá-las como base para todo o processo de descoberta e proposta de solução exigido na AP1.
